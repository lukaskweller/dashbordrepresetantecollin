# Collin Professional Dashboard 5.0 Executive Stable

Projeto pronto para GitHub Pages.

Arquivos:
- index.html
- styles.css
- app.js
- manifest.webmanifest
- service-worker.js
- data/clientes.json
- assets/icon.svg

Como publicar:
1. Apague os arquivos antigos do repositório.
2. Envie todos os arquivos deste ZIP na raiz do repositório.
3. Commit changes.
4. Abra o site com ?v=50 para limpar cache.

Dados atuais da planilha ATUALIZADA.xlsx já estão no fallback data/clientes.json.
O app tenta sincronizar com Google Sheets; se falhar, usa o JSON local para nunca travar em carregamento.
